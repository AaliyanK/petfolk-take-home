# records/

The 25 Vetspire medical record exports plus `_INDEX.txt`.

**These are Petfolk's assessment material and are not redistributed in the public repo.** The `.txt` files are gitignored. They are included in the zip sent to Petfolk so that copy is self contained and the verification script runs out of the box.

To reproduce locally: drop the 25 `.txt` files and `_INDEX.txt` from the take-home download into this folder, then run `working/scripts/verify_quotes.py`.

`doc_id` in each file's header is the identifier used throughout this repo.
